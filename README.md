# News Sentiment Analysis for Stock Movement Prediction

## Project Overview

This project analyzes the relationship between financial news sentiment and stock market movements using Natural Language Processing (NLP), technical indicators, and statistical correlation analysis.

The project is part of the 10 Academy Artificial Intelligence Mastery Week 1 Challenge.

## Objectives

- Perform exploratory data analysis (EDA) on financial news data
- Extract sentiment scores from financial headlines
- Compute technical indicators using TA-Lib and PyNance
- Analyze correlations between news sentiment and stock returns
- Generate actionable investment insights from combined qualitative and quantitative analysis

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- VADER Sentiment Analysis
- TA-Lib
- PyNance
- Matplotlib & Seaborn
- Git & GitHub Actions
